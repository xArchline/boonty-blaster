# Project

**Boonty Blaster**: an ad-style, addictive 2D mobile web game for Boonty (boonty.io). Hold to fire mini hedgehogs through multiplier gates and flood the Grumps' castle.
Owner / playtester: Laury. Priorities: FUN > CLARITY > POLISH > FEATURES.
